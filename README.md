# Proyecto de Netflix.

## Instrucciones de instalacion.
Para descargar este proyecto debemos de clonarlo y seguir los siguientes pasos.

1. Hacer una copia del fichero env.example y renombrarlo a .env.
2. Introducir el nombre del usuario,uid,gid en las variables.
3. Arrancar docker.
4. Ejecutar con boton derecho opcion ejecutar sobre el docker compose.yaml.
